# customersupport.project
# Demo Assistance Chatbot

A beginner-to-intermediate Python console application that simulates a customer support and account registration system.

This project was built while learning Python fundamentals and combines multiple real-world programming concepts into one interactive application.

---

## Features

* User account creation system
* Region selection validation
* Phone number verification
* OTP verification system
* Username validation
* Password strength validation
* Interactive support chatbot
* Manager contact option
* Input retry system using loops
* Function-based program structure

---

## Concepts Used

This project demonstrates understanding of:

* Functions
* Loops (`while`, `for`)
* Conditional statements
* String methods
* Boolean flags
* Input validation
* Lists
* Returning values from functions
* Passing arguments between functions
* User interaction flow
* Basic chatbot logic

---

## Validation System

### Username Requirements

* Must contain:

  * One uppercase letter
  * One digit
  * One special character
* Maximum 10 characters allowed

### Password Requirements

* Must contain:

  * One uppercase letter
  * One digit
  * One special character

### Phone Number

* Must contain exactly 10 digits

### OTP

* Must contain exactly 4 digits

---

## Example Flow

1. User creates account
2. Selects region
3. Verifies phone number
4. Enters OTP
5. Creates secure password
6. Enters chatbot support system
7. Receives support response
